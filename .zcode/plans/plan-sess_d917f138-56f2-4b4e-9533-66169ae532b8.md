## 0. Verified reality vs Plan 25's assumptions (forensic result)

Exploration confirmed the plan's counts (3 witnesses / 12 epilogues / 6 divisions / 4 live Muster systems) but **refuted its central mechanism assumptions**:

1. **No faction-action pipeline exists.** `holdfast_factions.json` "actions" are display dossiers (wants/offers); `standing_record_factions.json` is **dead data** (no loader); `foundry_faction.json` divisions are UI-only. The four Muster systems (`Assets/Ashfall.Core/Muster/ScavengerGuildSystem|HydroBaronsSystem|IronRaidersSystem|CoalitionCampSystem.cs`) are hand-rolled numeric state machines — no JSON loading, no action selection, no thresholds, no cooldowns.
2. **Witnesses are flat**: `muster_witnesses.json` (3 entries) = `{id, witness_name, location_id, knowledge_key, day_min, body}`. No variants, flags, faction, ordering. Loader rejects `schema_version > 1`. Core never evaluates witnesses (host UI gates `day_min` only).
3. **No war→Muster linkage**: `MusterSystem` triggers day-only (`MusterOpeningDay = 260`, `MusterSystem.cs:222`); zero references to `FactionWarSystem`/treaties. No "Muster path" derivation exists (only player-chosen Approach A–D → endingKey, e.g. `the_amnesty`).
4. **War spine is real but semantics-poor**: `FactionWarSystem` (standing −100..100, `WarTension` 0–100, friction starts day 240) + `FactionWarChainRunner` (22 chains/45 stages authored **minDay 480–605**; trigger grammar closed set: visited/chain-resolved/day-offset/AND; only effect = `moraleDelta`; no flag production/consumption). Campaign calendar has **no day cap** (day 360 = epilogue matrix view; play continues into the 480–605 war window).
5. **`RegionalTreatySystem` has a live gap**: tested Core system, but the host never calls `LoadCatalog` — empty in production. Treaty corpora (`narrative/regional_treaty_protocols.json` 16 treaties, `foundry_accords.json`) are narrative read-models on a different schema.
6. **Standing is fragmented**: `FactionStanceEngine` (trade), `PrpfStandingSystem`, and private `trust` floats inside guild/hydro states. IronRaiders has aggression/visibility only; raid-chance feed (`SetAggressionLevel`) has no production caller.
7. **Timeline anchor (repo pacing, per plan §11/§13.10):** grievances + escalation events → pre-Muster window (~day 200–300, friction backdrop from 240); Muster opens 260 (unchanged canon); hot-war mid-war + weariness events anchor to the authored 480–605 chain, weariness feeding the existing `evt_d588_ceasefire_by_exhaustion`. The plan's "war before Muster" ordering is re-sequenced to match authored canon; this deviation is recorded in the timeline doc.
8. **Known breakage at 15 witnesses**: `MusterContentCatalogTests.cs:52-55` (pins 3 ids), `src/Main.UiTests.Muster.cs:40` (`Count == 3`), `src/Main.Muster.cs:215-217` ("Three accounts" copy).

## 1. Architecture — four runtime seams (all Core, `Ashfall.Core.Muster`, engine-agnostic, no new standing authority)

**S1 FactionActionBoard** (`Assets/Ashfall.Core/Muster/FactionActionBoard.cs` + loader). New data authority `Assets/StreamingAssets/Data/muster_faction_actions.json` (snake_case, `schema_version: 1`): entries `{id, faction_id, title, min_day, max_day, once, cooldown_days, requires_flags[], variants:[{band: hostile|poor|neutral|good|allied, text, choices:[{choice_id, text, effects:{trust_delta, items[], flags[], journal}}]}]}`. Board deterministically selects available actions per day (day/flags/once/cooldown/standing-band; ordinal order), resolves choices through each system's **own existing state** (thin additive `AdjustTrust` seams on guild/hydro where missing; raiders band from aggression/visibility; camp from formed/members/lockout), writes produced flags to `IFlagLedger`, persists action history (id+day) for idempotence. `CaptureState/RestoreState` DTO → `MusterHostSave.FactionActions` (null-tolerant for old saves).

**S2 Witness schema v2 + selector.** `muster_witnesses.json` → `schema_version: 2`; entries gain optional `faction_id`, `priority`, `testimonies:[{variant_id, requires_any_flags[], requires_all_flags[], forbids_flags[], body}]`; v1 `body` = one unconditional testimony (loader back-compat, `CurrentSchemaVersion` bumped). New `WitnessSelector` (deterministic: day gate → eligibility → first-match testimony in authored order; ordering priority desc then id ordinal; optional cap with diversity rule) behind a Core port `IWitnessEligibility` (host binds flag ledger + survivor census — alive/dead never resurrect). Results (`witness_id → variant_id, delivered_day`) persisted in `MusterHostSave` for epilogue/Verdict consumption.

**S3 MusterPathEvaluator** (new Core class; additive `musterPath` field on `MusterState`, default empty for old saves). Pure deterministic function over existing state: `FactionWarSystem` (dominantFactionId, WarTension, standings), treaty read-model state, grievance/peace flags, camp state → `negotiated | victors | unsettled`. Evaluated at Muster resolution and re-evaluated on war-state change (idempotent). Drives camp-scene variants, witness pressure variants, and exposes `MusterPath` for epilogue/Verdict hooks. Existing Approach A–D selection remains the player choice; path is the political context.

**S4 War-event flag extension.** `FactionWarContentCatalog` DTO: optional `requires_flag`/`produces_flag` on stages, `requires_flag`/`produces_flag`/`standing_delta` on choices (standing via `FactionWarSystem.ModifyStanding`). One new trigger node `FlagTrigger` in the runner's closed set + explicit `FactionWarTriggerTable` entries (totality test already enforces). All 16 new chains authored into `faction_war_events.json` — 6 escalation E-P1..P6 ( grievance-gated, ~200–300), 6 mid-war E-W1..W6 (gated via **existing** `ChainResolvedTrigger` on real 480–605 battle stages), 4 weariness E-R1..R4 (culmination band → ceasefire 588).

**Cross-cutting:** bounded flag set `flag_grievance_*` / `flag_favor_*` (producer→consumer→resolution table pinned in the continuity matrix + lint test); new catalogs registered in `CatalogBootValidator`/`ContentUtilizationScanner`; political journal entries via existing host `TryAddRawEntry` pattern; culture codex via new `muster_faction_culture.json` + Core loader + codex panel extension (6 entries C1–C6). Treaty host feed: one isolated commit adapters `regional_treaty_protocols.json` → `TreatyDefinition` into `SetupRegionalTreaty` (revertible if it destabilizes; read-model fallback documented).
