## 1. Goal & Outcome
- **Goal:** Give every door/airlock arrival a **Claim** (stated) and a hidden **Truth** (Honest / Desperate liar / Agent / Defector-in-waiting / Bait), derived deterministically and drawn from the ten authored infiltrator profiles; let the player read tells and spend existing verbs (Inspect, watch, vet, detain, turn away, bait); convert a truth into an undercover-agent record only when the visitor becomes a survivor; build faction **dossiers** from the player's existing informant/intelligence records.
- **Outcome (observable):** on a fixed seed an arrival with an Agent truth shows profile-derived tells over three days; `VetCandidate` (finally called from the host) returns a result; admitting the agent lets it act its flags; a false accusation lowers standing with the visitor's true faction; state survives save/load.
- **Non-Goals:** no replacement of airlock, door-encounter, visitor-integration, counter-intelligence or informant systems; no new save section; no new routed panel; no new faction; no mandatory interrogation; no mind-reading; no Unity.
- **"Done":** §6 acceptance passes via `bin/run-scoped-tests`; ship-dark parity holds; handoff lists untouched shared paths.

## 5. Packages

### QW-P0 — Premise audit & gate convergence (Auditor; read-only)
- Close E11: which roster the door sees; who calls `AirlockSecuritySystem.VisitorArrives` in live play; how airlock admission reaches `VisitorIntegrationSystem` (`SourceVisitorId`); agree the shared gate adapter with LR-P6 and PY-P3/P4; foreman signs DEC-QW-01…10.
- **Accept:** one named decision point, one stay owner, one adapter design signed by three plan owners.

### QW-P1 — Claim/Truth deriver (Core, pure, seeded)
- Deterministic Truth from seed + world inputs (faction pressure, regional condition, Signature, outbreak); agents drawn from the ten profiles; mix weights in data; honest visitors are the majority by construction.
- **Accept:** table-driven mix test over N seeds within tolerance; same inputs → same truth; no RNG on quiet days beyond the fork's fixed shape.

### QW-P2 — Gate adapter & persistence (Host + Core nested DTO)
- On `VisitorArrives`, derive and attach Claim/Truth (nested); on Admit, hand off to `VisitorIntegrationSystem` with `SourceVisitorId`; door-encounter variants use the same derivation.
- **Accept:** round-trip; old saves load empty; idempotent handoff; ship-dark parity for airlock and visitor selftests.

### QW-P3 — Tells & interview (Core + content)
- Profile fields → first-three-day behaviours; interview questions on existing choice machinery; **Check the paper** consults dossier knowledge.
- **Accept:** a fixed agent profile yields its authored flags deterministically; tells never reveal Truth exactly; skill/loyalty mask modulates detectability.

### QW-P4 — Vetting, watching, detaining (Host wiring)
- `VetCandidate` finally called from the host with an officer; monitoring level via visitor system; Detain/Quarantine via airlock/CI APIs.
- **Accept:** each verb has one caller; costs (officer day, watcher hours) charged through existing duty/needs seams; no new authority.

### QW-P5 — Agents act, confess, are turned (Core via existing CI)
- On recruit/long stay, register an undercover-agent record keyed by the new `survivorId`; agents act flags; confession triggers; `AcceptDefector`; `ResolveSabotage`.
- **Accept:** visitor→survivor conversion registers exactly one agent; conversion never duplicates; an unrecruited visitor never becomes an agent record.

### QW-P6 — Accusation & fallout (Host)
- False accusation → standing hit with true faction through standing seam; grievance signal to *Shelter Governance* (soft); verdict/accusation systems consulted.
- **Accept:** honest-detained produces a cost; agent-detained produces a captive; no writes outside public APIs.

### QW-P7 — Dossiers (Core, pure) & bait
- Dossier per faction derived from informant/intel/intercept records; bait = a planted fact through a dead-drop template; repeat-detection reveals who is listening.
- **Accept:** dossiers reproduce from source records; bait outcome deterministic.

### QW-P8 — Presentation

- **Accept:** presenter tests; panels hold no authority; Truth never shown.

- **Accept:** absent inputs → neutral weights.

## 6. Acceptance criteria
1. Core authority + host owner + event path + persistence + observable outcome agree (CLAUDE.md "integrated").
2. Ship-dark parity: no `visitor_claims.json` → airlock, door, visitor and CI selftests unchanged.
3. Determinism: identical claims/truths/tells on replay.
4. Save round-trip mid-stay with a hidden truth and a watch level.
5. Exactly one agent record per converted visitor; none for unrecruited.
6. No writes to airlock, door, visitor, CI, or informant state except through public APIs.
7. The UI never exposes Truth.

## 7. Cross-plan boundaries
- **The Living Region:** Failing regions send desperate liars; the gate adapter is shared; QW owns Claim/Truth, LR owns petitions.
- **The Plague Year:** Screen at the gate is a *vetting* setting; a sick visitor is more likely honest; PY owns the dial, QW owns identity; both use the one adapter.
- **Radio Free Ashfall:** Signature raises attention; the "signal interceptor" profile bridges; RF owns the station.
- **Shelter Governance:** infiltrator trials, false-accusation grievance, `informant_use` scope.
- **Crews and Companions:** returning parties may bring a stranger; the same adapter applies.
- **The Reconstruction Tree:** fragments are contested intelligence; no shared state.
- **Year Two:** children are never agents; recruited visitors join the roster through existing paths.
