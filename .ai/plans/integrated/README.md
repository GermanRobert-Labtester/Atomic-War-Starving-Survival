# Integrated Agent Plans Archive

This directory stores agent task and feature plans that have completed execution and integration.

## Immediate Archival Rule
- When an agent plan in `.ai/plans/` or `.ai/plan.md` has been implemented, verified, and integrated, it must be **immediately** moved into this directory (under the appropriate category folder matching `docs/`, or directly into `.ai/plans/integrated/<category>/`).
- **Same-Session Rule:** Even if a plan was produced in the current session, once integrated within the same session, it must immediately be moved to the already-integrated plans folder before the session concludes or before moving to the next task.
- Subdirectories mirror all domain categories from `docs/` (`ui`, `systems`, `shelter`, `medical`, `ci`, etc.).
