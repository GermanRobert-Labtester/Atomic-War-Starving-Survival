## Bounded outcome

Three changes that cut agent wall-clock waste:

1. **Stop indexing the plan corpora in `docs/INDEX.md`.** `docs_index_drift` was
   measured at **215 s** scanning 5955 markdown files, **1472 of them under
   `docs/plans/`** — and that guard runs on *every commit*, so plan-integration
   closeout pays it every time. Plans already have an authoritative register
   (`scripts/ci/generate-plan-register.py`), so the general docs index does not
   need them.
2. **Reference-time budgets with a suspicion threshold.** A committed baseline of
   expected durations plus a checker that flags any run **≥ 25 % over** its
   reference (default tolerance 1.25, i.e. within the requested 20–30 % band).
3. **Make the mechanism reusable** for builds, gates, and audits so agents aim
   for a known range instead of letting a run silently go 3× over.

## Non-goals

- No game code, Core, data, save, determinism, or UI behavior change.
- No edit to `scripts/ci/run-gates.py` or `docs/ci/CI_GATE_MANIFEST.json`: both
  were modified by a concurrent session minutes before this work started, so the
  budget checker is **additive** and reads run-gates' existing `--report-json`.
- A single shared mutable baseline is not created: the baseline is a static,
  committed JSON reference updated deliberately, not a parallel live ledger.
