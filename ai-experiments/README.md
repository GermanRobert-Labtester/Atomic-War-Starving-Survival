# AI Experiments Lab (Python)

This directory is the dedicated Python research lab for:
- Prompt engineering experiments & notebooks (`.ipynb`)
- Agent prototypes (Google ADK Python, LangGraph, CrewAI, OpenAI Agents SDK, Smolagents)
- ML, embeddings, and RAG retrieval pipelines (Hugging Face, LangChain, LlamaIndex, Pydantic AI)
- Quick one-off exploratory scripts where speed of authoring matters more than runtime efficiency.

Production agents invoke persistent Go tooling (`bin/ashfall-dev`) for repository indexing, test selection, validation, and execution.
