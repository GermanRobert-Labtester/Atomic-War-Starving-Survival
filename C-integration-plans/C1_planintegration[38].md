# C1 — Flagship Integration Plan [38]: Survivor Interpersonal Conflict, Grievances, Mediation & Reconciliation

> **Output:** `C1_planintegration[38].md`
>
> **Source baseline:** Plan 202 — Survivor Interpersonal Conflict & Grievance System
>
> **Primary mission:** add grounded, deterministic non-ideological interpersonal conflict between survivors—arguments, resentment, fairness disputes, workload disputes, roommate friction, broken promises, personal slights, betrayal and reconciliation—while preserving the existing authorities for relationship affinity, ideological friction, survivor traits, needs/stress, duty assignments, morality, autonomy, survivor memory, injury/combat, governance and work output.
>
> **Primary architectural rule:** `InterpersonalConflictSystem` owns **conflict episodes, grievance claims, escalation state, resolution attempts, mediator involvement, settlement terms, conflict provenance and conflict-specific lifecycle history**. It does not own canonical relationship affinity, survivor personality traits, hunger/stress, duty assignments, ration allocations, inventory ownership, promises/quest truth, morality, physical injuries, combat outcomes, faction standing, or long-term NPC memory.
>
> **Primary modeling correction:** the source plan proposes a broad `Grievance` store plus separate relationship effects, daily accumulation, generic personality-clash tension, and direct morale/work consequences. The flagship narrows this to **source-backed grievance claims and conflict episodes**. A grievance must point to a real triggering fact or authored perception event. Conflict state may influence other systems through bounded adapters, but the same cause must not be penalized twice through Needs, Relations, Plan 137, mental health and conflict.
>
> **Primary causality rule:** conflicts should almost never appear from a free-floating random daily roll. RNG may determine whether an already-valid trigger becomes an overt argument, which interpretation is chosen, or which resolution path is attempted. The trigger itself should come from real events: unequal rations, stolen property, broken promises, excessive work, sleep disruption, ideological friction, humiliation, betrayal, incompatible duties, repeated boundary violations, or a genuine misunderstanding generated by a communication/narrative system.
>
> **Primary personality rule:** traits modify thresholds, interpretation, escalation and preferred resolutions; they do not create permanent hostility just because two tags are paired. `aggressive + sensitive = conflict forever` is explicitly rejected. Personality can raise risk only when survivors actually share context, compete for something, or experience a trigger.
>
> **Primary escalation rule:** physical fighting, sabotage and alliance formation are not generic numeric side effects. Each requires a real downstream authority and explicit transition contract. A high escalation score alone must not silently injure survivors, destroy items, change work output or create political blocs.
>
> **Primary memory rule:** conflict history and survivor memory are separate layers. Plan 147/per-NPC memory owns what a survivor remembers about another survivor or event; Plan 185 memory decay may later affect recall. InterpersonalConflict may create the source episode and grievance semantics, but it must not become a second permanent relationship-memory archive.
>
> **Mandatory execution order:** 202A social/relations/needs/duty/ideology authority audit → 202B conflict-template and trigger contracts → 202C grievance-claim state and aggregation → 202D escalation/de-escalation state machine → 202E apology/mediation/compensation/restitution/punishment/time resolution → 202F personality/needs/workload/roommate adapters → 202G relations/memory/morality/mental-health/combat integration → 202H player UI, alerts and explanation → 202I persistence/migration/determinism/idempotence → 202J long-horizon social simulations, exploit prevention and CI → 202K advanced feuds, alliances and shelter schisms only after canonical support exists.
>
> **Critical re-baseline rule:** before creating `InterpersonalConflictSystem.cs`, inspect `IdeologicalFrictionSystem`, `SurvivorRelationsSystem`, `SurvivorTraits`, `NeedsSystem`, stress/mental-health authority, `DutyRosterSystem`, ration/food allocation, room/bed assignment, inventory/property ownership if any, promise/favor/quest state, Plan-144 Survivor Autonomy, Plan-147 per-NPC memory, Plan-179 psychology, Plan-185 memory decay, Plan-188 routines, MoralChoiceSystem, survivor injury/combat, governance/leadership and semantic event infrastructure.
>
> **Guardrails:** no second relationship score; no conflict-owned morale stat; no generic daily grievance growth with no event; no personality-pair hostility table that acts without context; no arbitrary theft trigger if personal property does not exist; no broken-promise grievance without a canonical promise/favor fact; no generic jealousy roll without a modeled source; no direct work-productivity mutation when fatigue/stress/relations already account for it; no direct injury creation from “fight” unless combat/injury authority resolves it; no sabotage outcome without a sabotage/property/work system; no alliance formation without a real social-group/faction mechanic; no blanket punishment morality change; no punishment action that bypasses governance; no mediation skill duplicate; no per-frame pairwise scan of all survivors; no O(N²) daily trait-clash sweep for large shelters; no unseeded RNG; no `Guid.NewGuid`; no wall-clock time; no conflict-event/journal spam; no grind reward for provoking and repeatedly mediating trivial conflicts.

# 0. Mission

ASHFALL already has several pieces of social simulation, but they do not yet produce a general interpersonal conflict loop.

The source baseline identifies:
- `IdeologicalFrictionSystem.cs` for belief-driven conflict;
- `SurvivorRelationsSystem.cs` for affinity;
- `SurvivorTraits.cs` for personality traits;
- `NeedsSystem.cs` for hunger/stress and other survival pressures;
- no general argument/dispute/grievance system;
- no mediation;
- no resource/fairness/workload conflict;
- no generalized non-ideological reconciliation loop.

The current shape is roughly:

```text
IDEOLOGICAL DIFFERENCE ─► IdeologicalFrictionSystem
RELATIONSHIP             ─► affinity
TRAITS                   ─► personality
NEEDS                    ─► hunger/stress
DUTIES                   ─► assignment

but no unified:
trigger → grievance → conflict → escalation → resolution
```

The target architecture is:

```text
CANONICAL SOURCE EVENTS
      │
      ├── ration allocation
      ├── duty/workload
      ├── property loss/theft
      ├── promise broken
      ├── humiliation/slight
      ├── room/sleep disruption
      ├── ideological friction
      ├── autonomy refusal
      └── relationship/narrative event
      │
      ▼
ConflictTriggerObservation
      │
      ▼
InterpersonalConflictSystem
      │
      ├── grievance claim
      ├── active conflict episode
      ├── escalation band
      ├── source provenance
      ├── resolution eligibility
      ├── mediator participation
      └── resolution history
      │
      ▼
CANONICAL CONSUMERS
      │
      ├────────► SurvivorRelationsSystem
      ├────────► Plan 147 personal memory
      ├────────► mental health/stress
      ├────────► DutyRoster / room assignment
      ├────────► MoralChoiceSystem
      ├────────► governance/discipline
      ├────────► inventory/restitution
      ├────────► combat/injury if fight occurs
      └────────► Plan 171 dynamic narrative/quests
```

The conflict system should answer:

> What are these survivors disputing, what concrete event or perceived wrong caused it, how severe is the grievance, has the dispute become overt, how is it escalating, and what resolution actions are currently valid?

It should not answer:

> What is their canonical affinity?
> How hungry are they?
> Who owns the ration?
> Was the promise actually fulfilled?
> Which survivor is assigned which shift?
> Did a punch cause an injury?
> Was the punishment morally justified?

Those remain other authorities.

# 1. Source-Evidence Interpretation

## 1.1 General interpersonal conflict is genuinely absent

The source reports zero Core matches for:
- `InterpersonalConflict`;
- `SurvivorConflict`;
- `ArgumentSystem`;
- `DisputeSystem`;
- `GrievanceSystem`;
- `FightSystem`;
- `SurvivorDispute`;
- `PersonalityClash`.

A dedicated conflict coordinator is justified.

## 1.2 `SurvivorRelationsSystem` must remain relationship authority

Conflict may cause:
- affinity deltas;
- trust/grievance memory;
- reconciliation changes.

But those changes must be submitted through the relations system.

Do not store a second `relationshipEffect` as enduring truth.

## 1.3 `IdeologicalFrictionSystem` already owns ideology-specific trigger logic

Ideology can:
- emit a conflict trigger observation;
- influence escalation.

InterpersonalConflict should not duplicate belief-distance calculations.

## 1.4 Needs/stress are modifiers, not random conflict generators

Hunger, exhaustion and stress can:
- lower tolerance;
- increase escalation probability.

They should not create:
- a conflict target out of nothing.

There must be:
- interaction;
- competition;
- trigger;
- grievance source.

## 1.5 Several source triggers require canonical evidence

Examples:

### Unfair ration
Requires real:
- ration allocation;
- survivor expectation/entitlement or comparison.

### Stolen item
Requires:
- personal property/ownership;
- theft event.

If personal ownership is not modeled:
- do not fabricate the trigger.

### Broken promise
Requires:
- promise/favor/quest contract.

### Overworked
Requires:
- DutyRoster/workload history.

### Roommate conflict
Requires:
- actual room/bed co-occupancy plus disturbance/hygiene/noise or a relevant event.

### Jealousy
Requires:
- modeled status/relationship/property context.

Do not make “jealousy” a free random conflict type.

## 1.6 Physical fight and sabotage are downstream actions

They require:
- survivor autonomy;
- combat/injury;
- property/work systems.

High escalation alone should make them **eligible**, not automatically execute them.

## 1.7 “Time heals” should decay grievance salience, not rewrite history

Plan 147 memory and Plan 185 memory decay may affect:
- salience;
- recalled detail.

Relations may also recover.

InterpersonalConflict can reduce unresolved grievance pressure over time, but should not delete:
- the source event;
- historical conflict.

# 3. Definition of Done

Plan 202 closes only when:

- all social/relationship authorities are documented;
- ideological friction is explicitly separated from general conflict;
- conflict trigger producers are inventoried;
- unsupported triggers are deferred rather than simulated from nowhere;
- one conflict episode authority exists;
- grievance claims reference source events;
- latent grievance and active conflict are separate;
- escalation bands have explicit transition semantics;
- source 0–100 escalation remains a projection, not a second affinity score;
- personality modifies thresholds and preferred responses rather than creating constant passive hostility;
- needs/stress/workload affect escalation only through canonical inputs;
- room conflicts require actual shared-room conditions;
- ration fairness requires actual allocation facts;
- broken promises require canonical promise/favor facts;
- player/survivor mediation uses canonical social skill;
- apology, restitution/compensation, schedule reassignment, room reassignment and governance discipline act through real APIs;
- punishment is not treated as universally successful or morally correct;
- mediation can fail without automatically creating a new grievance against the mediator unless a real event occurs;
- relationship changes apply exactly once through `SurvivorRelationsSystem`;
- conflict memory flows to Plan 147 exactly once;
- Plan 185 decay can later reduce grievance salience without deleting source history;
- physical fights resolve through combat/injury/autonomy;
- work disruption is produced by actual refusal/absence/stress/relations effects, not direct conflict scalar multiplication;
- old saves start with no fabricated active conflicts;
- new conflict triggers begin only after feature activation;
- save/load preserves active disputes and unresolved grievances;
- no trigger/reload rerolls;
- no duplicate conflict for same grievance episode;
- UI shows cause, participants, escalation, current blockers and valid remedies;
- 30/120/180/400-day simulations show social tension without constant chaos;
- `--interpersonal-conflict-selftest` exists or equivalent;
- conflict-template data passes producer/consumer reachability.

survivor A's unresolved claim against survivor B
about source event X

- argument;
- confrontation.

- activation context.

- threshold;
- interpretation;
- response.

- cause.

---

# 10. Ideology Contract

IdeologicalFriction owns:
- belief friction.

- overt interpersonal episode produced by that friction.

---

# 11. Need/Stress Contract

- tolerance/escalation.

- actual physiological/mental need state.

# 12. Ration Fairness Contract

- policy.

# 18. Escalation Contract

- overt social risk.

- relationship affinity;
- stress.

# 19. Fight Contract

Crisis can request/enable:
- brawl.

Combat/injury systems resolve.

---

# 20. Sabotage Contract

Only a real sabotage action can cause:
- item/system damage.

Conflict cannot fabricate the damage.

---

# 21. Mediation Contract

Mediation:
- facilitates remedy.

It does not magically erase:
- source wrong.

---

# 22. Apology Contract

Apology can change:
- willingness;
- grievance state;
- relations.

It cannot:
- restore property;
- change work history.

---

# 23. Compensation Contract

- actual transfer/benefit.

No abstract token.

---

# 24. Punishment Contract

Governance owns:
- discipline.

Conflict provides case context.

---

# 25. Time-Heals Contract

Time may reduce:
- overt escalation;
- grievance salience.

History remains.

# 26. Memory Contract

- memory/salience.

Conflict keeps:
- source refs.

# 27. Morality Contract

# 28. Autonomy Contract

- stress;

# 55. Final Outcome

When this plan is complete, ASHFALL's survivors will finally be able to disagree about ordinary life—not only ideology.

A survivor who repeatedly receives the worst shifts can become resentful because the DutyRoster actually shows that workload pattern. Someone who loses sleep because of a real roommate disturbance can complain about the person or condition causing it. A broken promise can matter because the promise existed. An unfair ration can matter because the ration decision existed.

That causality is what makes the system believable.

Conflict does not begin with a random daily roll that decides two people suddenly hate each other. It begins with something that happened.

The survivor interprets that event through their personality, stress, prior relationship and current condition. A trusted friend may forgive a small slight. A survivor under severe pressure may confront it immediately. A repeated offense can strengthen an unresolved grievance. A low-affinity relationship can make the same event harder to absorb.

But personality does not substitute for cause.

Two survivors with different traits can live together peacefully for months if nothing actually goes wrong.

When a grievance becomes overt, the conflict gains its own lifecycle. It may remain low-level tension, become an argument, develop into open hostility, harden into a feud, or—if the rest of the simulation supports it—reach a physical crisis.

Every stage stays separate from the underlying relationship score.

The dispute explains *what they are fighting about*.
`SurvivorRelationsSystem` still explains *how they feel about one another overall*.

That separation also makes resolution meaningful.

An apology may work for an insult.
It may not be enough for stolen property.

Restitution can return what was taken.
A room change can solve repeated sleep disruption.
A shift reassignment can address real workload unfairness.
A ration-policy review can address perceived favoritism.
A mediator can help two survivors accept a remedy, but cannot magically undo the original wrong.

Severe betrayal may never fully disappear.

Even when a grievance is forgiven, the survivor can still remember what happened through Plan 147. Later, Plan 185 can affect how vivid that memory remains without rewriting the historical event.

The player therefore manages relationships through actual shelter decisions rather than an abstract “reduce conflict by 20” button.

The system also remains fair.

Punishment is not automatically correct.
The person who started an argument is not necessarily the guilty party.
A failed mediator does not automatically become an enemy.
A hungry survivor is more irritable, but hunger does not randomly select a target.
A personality clash does not exist unless real interactions create something to clash over.

Most importantly, ASHFALL gains social consequences without duplicating every social system around it.

Needs still own deprivation.
Duties still own work.
Relations still own affinity.
Traits still own personality.
Ideology still owns beliefs.
Morality still owns ethical consequence.
Memory still owns what survivors remember.
Combat and medicine still own physical harm.

The new layer owns the missing thing between them:

the dispute itself.

The result is a shelter where fairness, promises, shared rooms, resource pressure, workload, respect and betrayal can all matter socially—and where reconciliation feels earned because the player addressed what actually went wrong.
