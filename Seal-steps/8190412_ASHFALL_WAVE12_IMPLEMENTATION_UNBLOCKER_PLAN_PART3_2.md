# 0. OPERATING CONTRACT

## 0.1 Allowed terminal states

Each F-series task must terminate as exactly one of:

- **IMPLEMENTED** — the missing mechanism, contract, read model, retention rule, verification gate, or documentation layer is landed through canonical owners and all required focused gates pass.
- **DECIDED-DEFERRED** — product/architecture/release/process policy requires a signed decision; exact deferred scope and re-entry condition are recorded.
- **RETIRED** — obsolete convention, duplicate authority, stale plan layer, dead CI gate, or archival path is removed/unregistered with proof.
- **VERIFIED-RESOLVED** — repository `HEAD` already satisfies the task; redundant implementation is skipped and evidence recorded.
- **ROUTED-REPAIR** — investigation exposes a real production defect outside bounded scope; a separate repair package is registered with reproducible characterization.

No task may close as:
- “mostly done”;
- “manual verification only”;
- “probably bounded”;
- “future cleanup”;
- “TBD”.

1. **Godot remains authoritative; Unity stays retired.**
2. **Core remains engine-free.**
3. **JSON/data authority remains canonical.**
4. **One authority per concern.** No second shelter identity, community reputation, audio-state coordinator, save-retention owner, documentation index, or CI barrier registry.
5. **Deterministic replay.** No wall-clock simulation logic, unseeded randomness, or unordered iteration may affect Core outcomes.
6. **Claims before edits.**
7. **Exactly 20 procedural substeps per task.**
8. **Exactly four mini-substeps per mini-task.**
9. **Focused verification first.**
10. **Build warning baseline may not worsen.**

12. **No duplicate derived state.** Community reputation tags, mix states, retention summaries, and gate summaries should remain derived where possible.
13. **User-authored shelter names are data, not paths.** Never use the custom name directly as a filesystem path or save filename without a separate safe identifier.
14. **Audio remains presentation.** Audio may react to domain state but may not mutate simulation.
15. **Retention may not erase gameplay-critical facts.**
16. **Save compaction must be semantics-preserving for current simulation state.**

The F-series closes Wave 12 by moving from individual mechanics toward **identity, presentation coherence, long-run durability, and permanent engineering discipline**. - shelter name length and origin bonuses;
- community reputation thresholds;
- audio bus/cue counts;

- journal compaction windows;
- pair-history bounds;
- 400-year horizon;
- 5 MB save ceiling;
- 500 ms load ceiling;
- data-file counts;
- standing-gate runtime budgets.

Every one of those must be treated as a **claim to verify**, not a default to implement.

The safe implementation pattern is:

**current authority → verified policy/data → minimal contract → focused integration → deterministic/save proof → standing evidence.**

When F1–F4 are terminal, the team should not immediately create another implementation wave. The correct next action is the **final census and transition gate** above. If the repository is actually sealed, the correct outcome is release/hardening or maintenance—not artificial backlog creation.
