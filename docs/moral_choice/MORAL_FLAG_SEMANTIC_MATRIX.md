# Moral Flag Semantic Matrix

| Category | Flags | Meaning |
| --- | --- | --- |
| Mercy / restraint | `flag_spared_raider`, `flag_responded_distress` | A specific costly restraint or response happened. |
| Violence / coercion | `flag_executed_prisoner`, `flag_expelled_survivor`, `flag_sabotaged_rival` | A specific coercive decision happened; no procedure is encoded. |
| Scarcity / generosity | `flag_shared_rations`, `flag_hoarded_medicine` | A scarce resource was deliberately shared or withheld. |
| Shelter / community | `flag_sheltered_refugee` | A rejected outsider was admitted under the source event. |
| Common good | `flag_repaired_infrastructure` | Shared infrastructure was repaired at meaningful personal cost. |
| Accord / debt | `flag_broke_treaty`, `flag_honored_debt` | A negotiated obligation was ruptured or a meaningful debt was honored. |
| Records / memory | `flag_forged_record`, `flag_preserved_archive` | Institutional evidence was falsified or deliberately preserved. |
| Faction alignment | `flag_chosen_faction_side` | The player explicitly committed to an alliance; it does not identify the side. |

The flags are historical “ever happened” facts, not current standing, current treaty status, or moral-band labels.
