# Plan 126 Economy Audit

## New-item ranges

- Trade value: 3–24.
- Weight: 0.01–1.0.
- Stack maximum: 1–15.
- New consumable effects match existing baselines: Granary Bread matches the flatbread hunger band; Committee Water matches the full-water thirst band; Off-Ledger Medicine uses a restrained existing health-effect band.

## Value density

The high value-per-weight objects are intentionally institutional documents, but their base values are restrained. The existing catalog already contains higher-density references such as `item_charter_three_pages` (100 / 0.1) and `item_vouch_token_crossing` (50 / 0.1). Plan 126 does not exceed those existing outliers.

No repeatable faction buy/sell loop was added because the current faction catalog has no exact item buy/sell surface. No item was made a global currency substitute.

## Fungibility

- Fungible: bread, water, lamp oil, weighbridge chits, quarantine bands.
- Limited: granary receipts and arbitration tokens.
- Unique: charter stamp, ledger, rejection notice, map, charter draft, pouch.

The inventory model does not encode per-document owner, color, clause, or hidden capacity, so descriptions remain generic where the item state is generic.
