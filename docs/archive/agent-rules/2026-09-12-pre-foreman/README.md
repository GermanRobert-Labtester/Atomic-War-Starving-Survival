# Pre-Foreman Agent Rulebook Snapshot

This directory is a byte-preserved snapshot of the active root-level agent
instructions immediately before the AI Foreman governance rollout on
2026-09-12.

The snapshot preserves historical and user-authored instruction text that was
removed from the live context because it was stale, contradictory, or too
large to load efficiently on every agent turn. It is reference material, not
active authority.

Live authority is now rooted at `../../../../AGENTS.md`; operational workflow
state is held by the five root-level governance documents linked there.

Verify the preserved files from this directory with:

```bash
sha256sum -c SHA256SUMS
```
