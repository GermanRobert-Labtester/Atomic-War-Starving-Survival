# Character Placeholder Base & Shelter Physics Base

**Status:** placeholder art + real (minimal) physics base · **Created:** 2026-09-12

## Character placeholder art

Generated by `scripts/tools/generate-character-placeholders.py` into
`assets/sprites/Characters/`. Deliberately **non-real blockout mannequins** — a
base, not final character art.

| File | Size | Layout |
|---|---|---|
| `char_base_sheet.png` (slate) | 256×288 | 4 frames × 3 facings |
| `char_base_sheet_rust.png` | 256×288 | 4 × 3 |
| `char_base_sheet_olive.png` | 256×288 | 4 × 3 |
| `char_base_sheet_bone.png` | 256×288 | 4 × 3 |
| `PLACEHOLDER_MANIFEST.json` | — | labels all files |

Rows are **front / side / back**; columns are a 4-frame walk cycle. Runtime uses
`Sprite2D` with `hframes=4`, `vframes=3`. Each frame carries a `PLACEHOLDER`
stamp. `SurvivorActorView` picks a variant by survivor-id hash; if the sheet is
absent it falls back to the canonical portrait/`placeholder_survivor.png`.

## Shelter physics base (not placeholder)

`src/World/SurvivorActorView.cs` is a real **`CharacterBody2D`**:

- gravity (`980`), `UpDirection`, `FloorSnapLength`, `MotionMode.Grounded`;
- a capsule `CollisionShape2D` (origin at the feet);
- accelerated horizontal seek (`MaxSeekSpeed 74`, `SeekAccel 460`) toward the
  room anchor assigned by `HoldfastInteriorView`;
- `MoveAndSlide()` against static interior bounds;
- walk/idle animation driven by `IsOnFloor()` + `|Velocity.X|`.

`src/World/HoldfastInteriorView.cs` builds the static stage with
`BuildPhysicsBounds()`: floor, ceiling, and two side-wall `StaticBody2D`
colliders. Movement is **presentation only** — Core still owns room assignment,
needs, and radiation; the actor only walks to the anchor it is given.

## Regenerate

```bash
./launch.sh --generate-placeholders      # all packs + Godot import
# or just the characters:
python3 scripts/tools/generate-character-placeholders.py
bash scripts/ci/run-godot-bounded.sh --path . --import
```

## Verification

Focused self-test (proves the base works, not just compiles):

```bash
godot --headless --path . -- --shelter-physics-selftest
```

It spawns an actor, seeks a distant anchor across real physics frames, and
asserts: blockout sheet loaded, arrived within 12px, on-floor within 10px, frame
advanced. Last run: `sheet=True arrived=True grounded=True x=427.3 y=334.9 onFloor=True`.

Also covered by `--player-panels-uitest`, `--panel-bind-lifecycle-selftest`,
`--shelter-decor-selftest`, and `--dashboard-uitest`.

## Scope / non-goals

This is a **base**: no ragdoll, pathfinding, crowd avoidance, or per-room nav
meshes yet. Those are future layers that build on this body, not replacements.
