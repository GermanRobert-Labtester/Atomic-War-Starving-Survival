# Verdict Radio Machine Voice Guide

> **Core Philosophy:** Verdict radio is not a human voice, not a horror narrator, and not a sentient entity. It is automated infrastructure logging readings and executing pre-war maintenance cycles with chilling mechanical indifference.

---

## 1. Machine Voice Rules

### What to Author:
- Specific measurement units (`hPa`, `g/cm³`, `m`, `Hz`, `ms`, `permille`, `V`).
- Administrative terminology (`discrepancy logged as sensor offset`, `fault count: zero`, `hardware correction rejected by safety interlock`, `packet forwarded as valid`).
- Dry exceptions and scheduled deferrals (`reconciliation window remaining`, `analysis valid as filed`).
- Terse declarative syntax (1–4 sentences, <= 250 characters).

### What NEVER to Author:
- Emotional descriptors: *"We are afraid"*, *"Beware"*, *"Help us"*.
- Sentient menace: *"The machine is watching you"*, *"You cannot escape the count"*.
- Explanatory exposition: *"This proves that the government lied about the blast"*.
- Rhetorical questions or human conversational filler.
