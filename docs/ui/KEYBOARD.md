## Focus & Navigation Contracts

- **Initial Focus**: Every overlay open routes through `AshfallFocusPolicy.OpenWithFocus`.
- **Focus Trapping**: Active overlays trap `Tab` / `Shift+Tab` within their interactive child controls.
- **Spatial Navigation**: Directional navigation (`Up`, `Down`, `Left`, `Right`) is handled by `AshfallFocusNavigator.MoveDirection`.
- **Focus Restoration**: Dismissing an overlay via `Escape` or close button cleanly restores focus to the invoking opener.
- **Safe Mode**: Holding `Shift` during application startup boots into safe mode, bypassing custom user keybindings.
