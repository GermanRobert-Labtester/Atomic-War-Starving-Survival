**Phase 3 — presentation.** Bind a read-only projection to the current Godot screen. Show current status, eligibility, cost, result, and reason for refusal. **Phase 5 — focused acceptance.** The future implementation package should use `TEST_POLICY.md`: the smallest relevant Core tests, one save round trip for any changed state, one same-seed replay if behavior selects content or outcomes, one host route observation, and a Godot headless check only when that surface changes.
