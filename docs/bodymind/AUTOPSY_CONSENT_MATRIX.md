# Autopsy Consent, Kinship & Memorial Matrix

This document defines how survivor consent, surviving kin bonds, leadership overrides, and memorial ceremonies interact with the autopsy loop.

---

## 1. Consent Hierarchy

```
[ Deceased Prior Directive / Living Will ]
                  | (If None / Ambiguous)
                  v
[ Surviving Kin / Spouse / Bond Partner ] (via SurvivorRelationsSystem)
                  | (If Refused or No Kin)
                  v
[ Shelter Leadership / Public Health Emergency ] (Override with Moral Cost)
```

| Relationship Context | Consent Required? | Can Kin Refuse? | Player Override Option? | Override Consequence |
| :--- | :--- | :--- | :--- | :--- |
| **Living Kin Present (Bond > 50)** | Yes | Yes | Yes (Emergency Public Health) | Kin suffers -3 Morale, +2 Guilt, relationship trust loss. |
| **Living Kin Present (Bond <= 50)**| Yes | No (Advisory) | Yes | Kin neutral or minor discomfort (-1 Morale). |
| **Unidentified / No Surviving Kin**| No | N/A | Direct Approval | None. Standard scientific protocol. |
| **Suspected Outbreak / Epidemic** | Public Health Mandate| No | Automatic Approval | Kin understands necessity; minimal grief penalty. |
| **Forensic Homicide Investigation**| Inquest Authority | No | Legal / Defense Mandate | Relieves uncertainty for loved ones if truth is uncovered. |

---

## 2. Memorial Integration & Chronology Guards
1. **Burial Sequencing:** Autopsies must be performed while the corpse remains in the medical ward or morgue table. Once a burial or cremation is logged in `MemorialSystem`, autopsy is permanently blocked.
2. **Memorial Text Variant:** If an autopsy reveals an unexpected truth (e.g. poisoning vs sickness, or heroic radiation sacrifice), the resulting eulogy generated by `MemorialSystem` dynamically adapts to reflect the discovered truth.
3. **No Knowledge Farming:** Each deceased survivor ID can be autopsied at most once (`completedSpecimenIds`). Subsequent attempts are blocked.
