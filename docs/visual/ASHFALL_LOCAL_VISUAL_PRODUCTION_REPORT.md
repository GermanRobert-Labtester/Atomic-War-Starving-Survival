# ASHFALL Local Visual Production Report

## 1. Toolchain Discovered

Python 3, Pillow 12.3.0, ImageMagick, `pngquant`, `oxipng`, and Godot are
available in this workspace. The production source uses only Python/Pillow so
it remains deterministic and does not require network access.

## 2. AI Reference Tools Available

No AI reference was needed. The requested primitives—icons, masks, tiles, and
small FX sprites—are better served by editable local generation.

## 3. Existing Technical Visual Coverage

The project already has placeholder shelter, surface, and character packs plus
an existing generated-art pipeline. This change adds a separate reusable
starter pack and does not replace those assets or catalog fallbacks.

## 4. Assets Produced

Five framed HUD/status icons, two transparent decals, two seamless 256×256
material tiles, three transparent FX sprites, a 960×600 review sheet, and a
JSON manifest are generated by `scripts/tools/generate-visual-pack.py`.

## 5. Godot Integration

`launch.sh` now consumes `--generate-visuals` (aliases:
`--generate-graphics`, `--graphics`), runs the Python generator, and refreshes
Godot imports when Godot is available. Normal launches remain non-mutating and
print a hint if the pack has not been generated yet.

## 6. Runtime QA and Performance

The pack uses small PNGs (96–256px runtime sprites/tiles) with no shaders,
network calls, or high-cost rendering stack. Run the focused checks below after
generation:

```text
python3 scripts/tools/generate-visual-pack.py --check
git diff --check -- launch.sh scripts/tools/generate-visual-pack.py docs/visual/ASHFALL_LOCAL_VISUAL_*.md
```

The assets are isolated and ready for later scene/panel consumers; no gameplay
state is simulated inside the artwork.

## 7. Remaining Gaps

These are reusable production assets, not a replacement for per-item,
per-location, or per-character final art. Scene-specific placement and
state-reactive particle consumers should be added in a separately owned visual
integration package when a concrete screen is selected.
