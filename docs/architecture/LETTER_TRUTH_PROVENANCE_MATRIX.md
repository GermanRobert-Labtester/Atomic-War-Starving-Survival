# LETTER TRUTH & PROVENANCE MATRIX

## 1. Provenance Classification Framework
Every letter in the corpus is classified into exactly one primary truth and provenance category to prevent treating subjective human testimony as objective simulation state.

| Provenance Class | Description & Semantic Rule |
|---|---|
| **Delivered Correspondence** | Written and delivered to its intended location or recipient. Discoverable as an environmental artifact left on a desk, tray, or counter. |
| **Unsent / Private Artifact** | Written but never delivered; kept in private pockets, book margins, or hidden caches. Discovery represents uncovering private interior thoughts. |
| **Historical Testimony** | Correspondence recording pre-crisis or early-crisis historical events (Days 1–15). Fixed historical context. |
| **Campaign-Contemporary Artifact** | Authored to coincide with mid-campaign shelter operations (Days 16–65+). Reflects lived crisis pressures. |
| **Ambiguous Testimony** | Narratives where the author's perceptions are subjective, uncertain, or unverified by external evidence. |
| **Unsafe / Unresolved** | Reserved for conflicting lore. (0 entries in current audited corpus). |
