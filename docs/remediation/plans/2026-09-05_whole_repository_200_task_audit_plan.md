## How to use this plan

- Each task is intentionally small enough to hand to a downstream agent in batches of 2–5.
- `Evidence` means a current-source file, command result, or explicitly labeled historical report. Historical audit findings are revalidation targets, not automatically active defects.
- A task is complete only when its stated verification passes on the current working tree and any changed authority, UI route, and persistence contract are traced end-to-end.
- UI design tasks must use `google-stitch` first, then reconcile the proposal with the Godot theme and Core binding rules. Audit-only tasks remain read-only.
