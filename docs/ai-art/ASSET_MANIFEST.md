## Destination gate

The gameplay scene is currently a 1920×1080 UI Toolkit layer over a near-black orthographic camera. Inventory code requests `Art/Items/<item_id>` and falls back to `iconRef`, so every item below has a real destination. Current survivor and location ScriptableObjects contain no image field, their visible UI panels contain no image element, and weather/faction art is not bound in the current presentation. Those placeholder families are therefore **NOT NEEDED in this run**, not silently treated as complete.

The live master list contains legacy real-world firearm names. They remain in the audit because IDs and display names cannot be invented or silently changed; production prompts translate them into unbranded geometry with no logos, flags or insignia. Canon cleanup of those source names is outside this visual-only pass.

## Production handling

1. Generate raw files only in `generated_AIassets/`.
2. Apply the human paintover and authorship checklist in `docs/HUMAN_AUTHORSHIP.md`.
3. Import the approved PNG to `Assets/Resources/Art/Items/<item_id>.png`; this path wins at runtime.
4. Optionally synchronize `Assets/_Game/Sprites/Items/<item_id>.png` for the legacy ScriptableObject fallback.
