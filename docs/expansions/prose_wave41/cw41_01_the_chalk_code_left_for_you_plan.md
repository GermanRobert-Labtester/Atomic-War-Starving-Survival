## 1. Expansion thesis

Checkpoint Kilo is a concrete room of mostly empty racks, sealed lockers, and a rusted lock, but its most lasting object is a chalk code written by someone who did not set the keypad. A cassette set records the checkpoint’s last forty-seven days, including a failing filter and a warning to trust lungs over gauges. A current distress quest places Sergeant Voss and a pinned patrol in the same location’s moral shadow. This bank follows inherited access, unreliable instruments, and the human cost of deciding whether a gate should open for you.

## 2. Story question

When a stranger leaves a way through a locked gate, what does the next person owe the kindness that made entry possible?

### Wild card
