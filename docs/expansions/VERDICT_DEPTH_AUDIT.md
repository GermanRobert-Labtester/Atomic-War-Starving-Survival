# Verdict Depth Audit (Expansion 08)

## 1. Subsystem Coverage

The Verdict represents the evidentiary, severe, and ideological reckoning of late-campaign decisions.

### Key Metrics
- **Questlines:** 16 questlines (8 core machine inquests, 8 forensic procedure & appellate lines).
- **NPCs:** 9 NPCs (including 3 new institutional roles: defense clerk Tomas Reid, machine-cult deaconess Elena Vane, archival custodian Kasper Holt).
- **Locations:** 4 high-security bunker complexes (Geophone Pit 1, Twelve-Gauge Array, Network Fuse Bunker, Archive Tape-Silo).
- **Systems:** `ReckoningSystem`, `MachineLogSystem`, `EvidenceLedger`, `VerdictCensusBroadcast`.

## 2. Deepened Mechanics
- **Forensic Admissibility:** Mechanical time-clock escapement authentication, taped signal eyewitness depositions, and UV rag-paper watermark testing.
- **Appeals & Reconsideration:** Seismograph shockwave telemetry appeals and overturned dereliction sentences.
- **Evidentiary Integrity:** Compromised transit chain-of-custody rulings, oxidized relay contact overrides, razor-cut punch card forgery inquests, and dual-operator torque reconciliations.

**Phase 2 — content.** Add a small cohort of authored entries to the existing JSON family. A catalog row with no loader or no reachable trigger is not accepted.

**Phase 3 — presentation.** Bind a read-only projection to the current Godot screen. Show current status, eligibility, cost, result, and reason for refusal. Preserve focus, close/back behavior, disposal, and refresh after a command and after restore. Text must describe the actual state; do not announce future consequences that the owner does not implement.

**Phase 4 — persistence and day ordering.** Confirm whether the live section already contains the state. Add fields only through the owning codec and old-save defaults. Order daily producers before consumers and explain which fact is sampled before mutation. One day tick must not be repeated after reload. Maintain deterministic iteration and the seeded stream.

**Phase 5 — focused acceptance.** The future implementation package should use `TEST_POLICY.md`: the smallest relevant Core tests, one save round trip for any changed state, one same-seed replay if behavior selects content or outcomes, one host route observation, and a Godot headless check only when that surface changes. This documentation pass runs static review only.
