## 1. Expansion thesis

The Wrong Size expands the filtration fixture about a spare belt, a wrong size, a second blower, and the fact that nothing else has ever fitted either. ## 2. Story question

When a spare belt hangs on a filtration-room hook but is clearly the wrong size, kept because nothing else has ever fitted either blower, what does keeping the wrong thing say about hope?
