Order daily producers before consumers and explain which fact is sampled before mutation. One day tick must not be repeated after reload. Maintain deterministic iteration and the seeded stream.

**Phase 5 — focused acceptance.** The future implementation package should use `TEST_POLICY.md`: the smallest relevant Core tests, one save round trip for any changed state, one same-seed replay if behavior selects content or outcomes, one host route observation, and a Godot headless check only when that surface changes.
