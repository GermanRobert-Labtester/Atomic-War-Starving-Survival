Each plan provides six movements, 48 beat pairings, and four alternative passage forms per pairing. Nine anchors are in the separate expansion catalog whose current runtime loading is unverified; the pianist plan uses the base-catalog record and documents a conflicting same-ID expansion variant. Each file contains 600,000–1,000,000 Unicode code points.
