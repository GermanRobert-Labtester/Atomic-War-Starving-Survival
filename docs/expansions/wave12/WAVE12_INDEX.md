## Wave theme

Each story turns on a threshold that had a practical purpose and a human interpretation: a service gate, a held bed, and a pair of coast records filed under one location. The characters do not reach a unanimous verdict. The player’s work is to leave the next reader a more truthful account.

## Source and promotion notes

The plans are grounded in the current location, expedition, world-map, damaged-map-zone, quest, collectible, and narrative-chain records. Expansion 67 preserves two live descriptive differences for a required premise audit: the location entry calls the destination an automated contingency shelter, while the coast-zone entry calls it a submerged maritime relay station. The existing Last Rotation engine requires item_archive_index_cylinder; its quest synopsis says “Microfilm index cylinder.” The plan flags both discrepancies for verification rather than adding a new item or resolving them by invention.

Before implementing any plan, recheck current content authority, fragment consumers, map reveal behavior, save ownership, and character-name collisions. These documents do not change production code or data.
