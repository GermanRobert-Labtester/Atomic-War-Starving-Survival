## Wave focus

The common constraint is reachability through one truthful authority per concern. Outposts use the existing colony and expedition owners; alerts close the loop around incidents and protocol execution; gatherings and memorials use current campaign time and history; tactile work remains a presentation of existing commands; scenario openings compose existing profile catalogs instead of creating parallel gameplay authority.
