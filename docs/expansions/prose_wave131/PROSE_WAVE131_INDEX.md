# Prose Wave 131 — Roads, Measures, and Words That Refuse a Name

Twenty source-grounded, prose-first plans expanding unused faction-war radio broadcasts and communiqués. Each file contains a 192-candidate bank (six movements × eight source-specific focal points × four optional forms). Candidate prose is editorial material, not live content and not a feature proposal.

The radio rows are loaded from Assets/StreamingAssets/Data/faction_war_radio.json by the local faction-war content catalog; RadioBroadcastCatalog also reads that file. The communiqué rows are loaded by the same faction-war content loader into FactionWarContentCatalog. These paths verify data ownership, not player-facing delivery of proposed prose. The batch uses 13 broadcast rows and nine communiqué rows across 20 plans; two plans pair related communiqué records. Any authorNote in a reproduced source row remains editorial metadata and is not treated as diegetic dialogue or candidate prose. Its continuity facts constrain authorship without being spoken by the source voice.
