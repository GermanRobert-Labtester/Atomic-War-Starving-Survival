```text

L2: ladder + fixtures; corruption kit; budgets measured
L3: culture/replay enforced; leakage enforced; boundaries audited
```

The plan's closure criterion is L3; L4 is the standing state it protects.

## XXV.7 The anti-rot rule

A gate that no longer runs is worse than no gate: it advertises safety it does not
provide. Every gate has an owner, a trigger, and a monthly "did it run" line in
the report.
