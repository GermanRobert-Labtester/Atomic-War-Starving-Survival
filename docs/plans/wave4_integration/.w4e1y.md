# W4-01 · PART XXVI — SECOND SCENARIO BANK AND REVIEW DRILLS

## XXVI.1 Scenario bank 2 (S11–S20)

**S11 — The interrupted upgrade.** Mid-migration process kill. Assert: original
file intact; migration restarts cleanly; no partial write visible. Class: recovery.

**S12 — The encyclopedic player.** Journal with 900 entries + load. Assert:
retention keeps meaning (summaries), size bounded, no orphan consequence keys.
Class: growth + semantics.

**S13 — The shared machine.** Two installs share a save folder (copy). Assert:
loads work; no path assumptions; checksum equal. Class: portability.

**S14 — The rollback.** New build writes v9; player reinstalls v8; v8 refuses with
reason or reads per declared policy. Class: forward compatibility.

**S15 — The marathon.** 6-hour continuous session with periodic saves. Assert: no
timer/save drift; memory stable; capture time stable. Class: endurance.

**S16 — The polluted profile.** Profile store with stale schema. Assert: migration
of profile independent; slot loads unaffected. Class: boundary.

**S17 — The renamed enum.** A faction rename in data. Assert: saves with old names
migrate; no ordinal reliance. Class: wire.

**S18 — The empty world.** All sections default; neutral load plays 30 days.
Class: neutral fare.

**S19 — The clock change.** System timezone/DST changes across a save. Assert:
digest unchanged; no durable clock. Class: determinism.

**S20 — The hotfix.** One-line gameplay fix mid-campaign. Assert: no save shape
change; no migration; ladder untouched. Class: stability.

## XXVI.2 Drill sheets

**Drill 1 — ledger archaeology (10 min).** Given an unfamiliar module, produce
its ledger rows in the template. Where unknown, mark "verify". A drill outcome of
three or more "verify" marks means the ledger sample needs refresh.

**Drill 2 — capture/restore audit (15 min).** Given a section, write its matrix
top to bottom; find one asymmetry and classify it (intentional or defect).

**Drill 3 — migration staff ride (20 min).** Take the oldest fixture and narrate
each transform out loud: why it existed, what it preserved, what it defaulted.
Any transform that cannot be narrated is a documentation gap.

**Drill 4 — failure copy table read (5 min).** Read the five canonical messages
aloud. If any sounds like a programmer wrote it, rewrite.

**Drill 5 — leak hunt (15 min).** Pick a random service; trace its lifetime across
a slot switch in the diagram; mark every place it is nulled or recreated.

## XXVI.3 The quarter's game

Once a quarter, the team plays one hour of a seeded fixture campaign, saves
aggressively, switches slots, and writes down anything that felt wrong. Saves are
about trust; trust is felt in play. The report feeds the queue.
