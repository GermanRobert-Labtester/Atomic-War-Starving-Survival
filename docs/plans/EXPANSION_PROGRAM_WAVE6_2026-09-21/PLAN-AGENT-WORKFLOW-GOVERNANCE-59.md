# PLAN-AGENT-WORKFLOW-GOVERNANCE-59 — Rulebooks, Skills, Prompts & Role Truth

**Wave 6 · Kind:** GAP SEALING · **Status:** PROPOSED — foreman claim required.

**Expanded appendix:** [`PLAN-AGENT-WORKFLOW-GOVERNANCE-59_APPENDIX-A_SKILLS_INVENTORY.md`](PLAN-AGENT-WORKFLOW-GOVERNANCE-59_APPENDIX-A_SKILLS_INVENTORY.md)

**Non-goals:** no vendor-specific agent features, no hidden automation, no
secrets in prompts (rule 9).

## Outcome
The repo instructs many agents: `AGENTS.md` plus 13 client rulebooks synced by
`sync-agent-rulebooks.py`, a skills catalogue generated by
`generate-agent-skills-catalog.py`, and a workflow document
(`AI_AGENT_WORKFLOW.md`). This audit found the rulebooks drift from the
register (blocked list stale) and claims rot (46 open). This plan makes agent
governance **generated and checked**, not manual.

| Deliverable | Detail |
|---|---|
| Rulebook truth | one canonical source per section; client files generated; a gate fails on drift or on naming a non-existent authority |
| Skills truth | every `.agents/skills/*` entry has a valid SKILL.md, a trigger, and a catalogue row; dead skills retired |
| Prompt hygiene | templates and examples contain no secrets/PII; a scan enforces; no instructions that contradict the invariants |
| Role mapping | foreman/builder/sweep/reviewer/integrator roles map to concrete commands and artifacts |
| Claim sync | claims ledger and rulebooks agree (ties to PLAN-DEBT-DRAIN-24 DD-24B) |
| Stale-reference gate | rulebook text mentioning `INTEGRATION_PLANS` rows must cite live ids; dead ids fail |

## Evidence
- `AGENTS.md` (10,573 B) + 13 synced client rulebooks (~10.4 KB each).
- `scripts/ci/sync-agent-rulebooks.py`; `AgentRuleIntegrityTests` retargeted to current invariants.
- Skills: `.agents/skills/` (36 entries) + generated catalogue gate.
- Known drift: AGENTS.md blocked list vs `DECISION_REGISTER` (301 rows, 2 non-terminal).
- `AI_AGENT_WORKFLOW.md` roles table and handoff format.

## Packages
- **AG-59A** rulebook generation: section-level canonical sources + template rendering; `--check` fails on drift.
- **AG-59B** stale-reference gate: references to plan/debt/register ids must exist; AGENTS.md queue lists generated from `INTEGRATION_PLANS.md`.
- **AG-59C** skills hygiene: validate each SKILL.md (frontmatter, description, location), retire dead ones, regenerate catalogue.
- **AG-59D** prompt/secret scan: scan `.agents/`, `docs/prompts/`, and templates for secrets and PII patterns; fail on match.
- **AG-59E** role contract: each role's allowed/forbidden actions as a checklist with the evidence artifact required after each action.

## Acceptance & verification

- `python3 scripts/ci/sync-agent-rulebooks.py --check`; `bash scripts/run_test.sh Ashfall.Core.Tests/Tooling/AgentRuleIntegrityTests.cs`; skills catalogue gate.
