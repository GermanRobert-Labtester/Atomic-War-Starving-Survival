## 2. Methodology

1. Mechanically enumerate every `*planintegration*.md` file — no numeric-continuity assumption.
2. Extract source baseline, mandatory order, declared dependencies per header.
3. Cross-reference `INTEGRATION_PLANS.md`, `WORKTREE_OWNERSHIP.md`, `KNOWN_DEBT.md`, `docs/**/*CLOSEOUT*`, and the Wave 8/9 closeouts.
4. **SEALED requires source + acceptance + closeout proof** (§7.2); a closeout **filename** is not identity. A candidate match is accepted only when the closeout's subject words intersect the corpus title — otherwise it is recorded as a **numbering collision**, not sealed.
5. Build the declared-dependency DAG; rank the executable frontier.
