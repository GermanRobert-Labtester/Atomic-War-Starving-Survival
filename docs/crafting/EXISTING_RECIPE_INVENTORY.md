## Notable baseline observations

1. **Station registration gap (proven defect, fixed by Plan 55):** only `workbench`
   was ever registered at runtime (`CraftingHostSession.SeedStation` +
   `Main.World.SyncCraftingStationsFromShelter`). The `stove`, `heater` and
   `water_purifier` stations referenced by ~30 recipes had no runtime
   registration path. Plan 55 bridges them to `room_kitchen`, `room_generator`
   and `room_filtration` respectively (`Main.World.SyncRoomStation`).
2. **`distiller` station has no owner** — 4 legacy recipes
   (`brew_lethe_substitute`, `craft_distilled_spirits`, `craft_fuel_gel`,
   `craft_antiseptic_solution`) remain unreachable. Flagged; not bridged
   because no shelter room represents distillation apparatus.
3. **Reloading provenance gap (proven defect, fixed by Plan 55):**
   `reloading_primer` and `smokeless_powder` existed only in items/recipes —
   no loot or trade source. Plan 55 adds them to `table_loot_military_depot`
   and `table_loot_police_station`.
4. **`antiseptic` dangling reference (flagged, NOT fixed here):**
   `medical_texts.json` requires item id `antiseptic` for 3 treatments, but no
   such item exists (`antiseptic_1l_of_1l` does). Belongs to the medical
   authority, not crafting.
5. **Mixed ID conventions:** legacy recipes use `craft_*`, `recipe_*` and bare
   verbs (`purify_water`, `boil_water`, `cook_meat`, `reload_*`). No loader
   prefix rule is enforced; Plan 55 uses `craft_*` / `reload_*` consistently.
