## Authority firewall

The numeric fields are carried by `NarrativeDiscoveredRecord.NumericClaimLabel` for presentation. They are never passed to `RadiationSystem`, any foundry or crafting system, any audio/seismic system, `FactionStandingIdResolver`, `MemorialSystem`, survivor state or a quest/effect dispatcher. Tags are retained as search metadata only. Group labels are not canonical faction IDs.

The only curated related edges are adjacent records within the same authored Cobalt, Iron Synod or geophone corpus. They are stored as manifest IDs, shown only when the target has also been discovered, and are not runtime-inferred from tags or prose. Epitaphs have no asserted cross-document identity edges.
