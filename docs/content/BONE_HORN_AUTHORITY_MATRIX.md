# Bone, Horn & Antler Authority Matrix

| Fact or action | Authoritative owner | Plan 160 projection | Forbidden interpretation |
|---|---|---|---|
| Authored preparation, sawing, polishing and assay prose | BoneHornCarvingCatalog / BoneHornSourceAdapter | verbatim body plus labelled summary | no executable process |
| Living animals and wildlife populations | wildlife systems and catalogs | none | no animal death, spawn or harvest |
| Survivor identity, life and death | survivor and memorial authorities | no identity links | dog/cat material cannot target a companion |
| Item existence and quantity | Inventory | none | no bone, horn, blank, saw or abrasive is created |
| Recipe transformation, cost and duration | Crafting / recipe authority | optional future context only | prep days are not craft timers |
| Item durability and quality | item-condition authority | none | point angles and finishes do not modify quality |
| Combat damage or penetration | Combat | none | point angle is not damage or penetration |
| Fishing, sewing and repair effectiveness | respective equipment/repair systems | descriptive context only | no hidden skill bonus |
| Trade value | Economy | none | prose rarity does not set price |
| Manual/research unlocks | existing manual/research systems | no automatic award | reading a log does not create a tech node |
| Discovery and journal history | NarrativeDiscoveryCatalog and JournalSystem | 30 stable discovery IDs | no duplicate rewards on reload |
| Producer context | existing shelter rooms and location inspection routes | seven active contexts | station labels are not new world locations |

Numeric fields are rendered as authored observations. prep_duration_days is a historical preparation duration, point_angle_degrees is historical geometry, and sawing/polishing labels are provenance. The adapter has no generic effect dictionary, reflection path or downstream mutation callback.
