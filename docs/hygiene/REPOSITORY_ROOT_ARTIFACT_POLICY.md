# ASHFALL — Repository-Root Artifact & Hygiene Policy

**Date:** 2026-08-27
**Scope:** Enforces strict root directory hygiene, defines allowed root files, directs generated outputs to dedicated directories, and specifies local AI tool cache isolation rules.

---

## 1. Allowed Root Artifacts

The repository root must remain lean and strictly governed. Only the following files and directories are permitted at root:

| Category | Allowed Items | Purpose |
|---|---|---|
| **Engine & Build Authority** | `project.godot`<br>`Ashfall.slnx`<br>`Ashfall.csproj`<br>`Directory.Build.props`<br>`Directory.Packages.props`<br>`global.json` | Godot 4.7+ project configuration, .NET solution, host C# project, build properties, central package management, and pinned .NET SDK. |
| **Project Directives & License** | `README.md`<br>`AGENTS.md`<br>`LICENSE`<br>`.editorconfig`<br>`.gitattributes`<br>`.gitignore` | Project entry point, master architectural directives, open-source license, editor configuration, Git LFS policy, and ignore patterns. |
| **Agent Rule Mirrors** | `CLAUDE.md`, `CODEX.md`, `CRUSH.md`, `GOOSE.md`, `QWEN.md`, `VIBE.md`, `MIMOCODE.md`, `OPENSETUP.md`, `ANTIGRAVITY.md`<br>`.clinerules`, `.cursorrules`, `.windsurfrules` | Canonical rule mirrors synchronized across AI clients via `ashfall-agents-sync`. |
| **Authoritative Source Trees** | `Assets/Ashfall.Core/`<br>`Assets/StreamingAssets/Data/`<br>`assets/`<br>`scenes/`<br>`src/`<br>`Ashfall.Core.Tests/`<br>`docs/`<br>`scripts/`<br>`tools/`<br>`snapshots/` | Simulation Core, JSON data authority, Godot native assets, scene files, Godot host C#, test suite, documentation, CI/maintenance scripts, tooling, and golden UI snapshots. |

### Strictly Prohibited at Repository Root

- ❌ **No loose test or execution logs**: `*.log`, `*.xml`, `test-results-*.xml`, `em.xml`, `pm.xml`, `lay.xml`, `build_log.txt`.
- ❌ **No transient codebase exports or dumps**: `unity_codebase.txt`, `files_to_check.txt`, `temp_*`.
- ❌ **No loose ad-hoc scripts**: `fix_*.py`, `fix_*.sh`, `safe_fix.py`, `test_*.py` (place in [`scripts/maintenance/`](../scripts/maintenance/README.md) or [`scripts/ci/`](../scripts/README.md)).
- ❌ **No loose visual art or renders**: `*.png`, `*.jpg`, `codex_alt_*.png` (must live in [`assets/`](../../assets/) or [`snapshots/`](../../snapshots/)).

## 2. Dedicated Folders for Generated Outputs

All generated reports, manifests, snapshots, and build artifacts must be routed to their authoritative locations:

```
├── snapshots/                         # Authoritative golden UI panel snapshot images (tracked)
├── snapshot-capture/                  # Ephemeral/transient snapshot diff renders (gitignored)
├── docs/
│   ├── INDEX.md                       # Master docs index (generated by generate-docs-index.py)
│   ├── ci/
│   │   └── SELFTEST_MANIFEST.json     # Machine-readable test manifest (generated by generate-selftest-manifest.py)
│   ├── cli/
│   │   └── HOST_CLI_COMMAND_CATALOG.md # Generated CLI command catalog (generated by generate-cli-catalog.sh)
│   ├── saves/
│   │   └── SAVE_STORE_CONTRACT_MATRIX.md # Generated save store matrix (generated by generate-save-store-matrix.sh)
│   ├── architecture/
│   │   └── ARCHITECTURE_TEST_MAP.md   # Generated architecture test map (generated by generate-architecture-map.py)
│   └── hygiene/
│       └── REPO_HYGIENE_REPORT.md     # Periodic repository hygiene report (generated by repo-hygiene-report.sh)
├── .godot/                            # Godot engine import and Mono temp cache (gitignored)
└── bin/ , obj/ , target/              # .NET and Rust build outputs (gitignored)
```

## 3. Ignored Local-Tool Cache Guidance

AI coding tools and local development harnesses generate ephemeral state, indexing caches, and embedded databases. These must remain **gitignored and never staged in git commits**:

| Tool / Cache Directory | Default Path | Git Status | Policy |
|---|---|---|---|
| **Aider Cache** | `.aider*`, `.aider.tags.cache.v4/` | `gitignored` | Contains tag index caches (`cache.db`). Never commit. |
| **Crush / Agent DBs** | `.crush/`, `crush.db` | `gitignored` | Local SQLite embeddings database. Never commit. |
| **Composio MCP Cache** | `.composio/` | `gitignored` | Local tool discovery and socket state. |
| **Mimocode / Qlty Caches** | `.mimocode/`, `.qlty/`, `/.commandcode/` | `gitignored` | Local analysis caches. Never commit. |
| **AI Art Generation Staging** | `generated_AIassets/`, `.mistral/` | `gitignored` | Raw prompt outputs; only curated and approved assets move to `assets/art/`. |

## 4. Verification & Hygiene Audit Commands

Run the automated hygiene inspection before opening pull requests or creating release tags:

```bash
# Audit repository hygiene, stray binaries, and cache directories:
bash scripts/ci/repo-hygiene-report.sh

# Verify git ignore rules against test paths:
git check-ignore -v <path>

# Run full fast verification gate suite:
bash scripts/ci/verify-fast.sh
```
